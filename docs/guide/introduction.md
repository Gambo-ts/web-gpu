# Introduction

Gambo Starter is a from-scratch TypeScript rewrite of a 22-lesson WebGPU
tutorial set, rebranded and restructured as a self-contained scaffold. No
lesson depends on an external tutorial site anymore — everything either ships
as a local npm dependency or lives in this repo.

## What you'll learn

- The WebGPU rendering pipeline: shader modules, render passes, and the swapchain
- Compute shaders and GPU-side data processing
- Buffers: vertex buffers, uniform buffers, and storage buffers
- Matrix math and transforms: translation, rotation, scaling, and projection
- Textures: sampling, mip-mapping, and importing images from the browser
- Inter-stage variables and the vertex → fragment data flow

## Requirements

- A browser with WebGPU enabled (Chrome / Edge on a GPU-supported device)
- Node.js and npm
- TypeScript familiarity helps but isn't required
