# Lessons

Twenty-two lessons, grouped by topic. Each lesson is a standalone Vite entry
point reachable at `/lessons/<topic>/<name>/` in dev and in the static build.

## Fundamentals

The starting point: a first render pass and a first compute shader.

- [Render Intro](/lessons/fundamentals) — draw your first triangle
- Compute Intro — run your first compute shader

## Buffers

Vertex, uniform, and storage buffers — how data gets to the GPU.

- Vertex Buffers — feeding geometry to the vertex shader
- Uniforms — per-draw data shared with shaders
- Storage Buffers — large, GPU-writable data arrays

## Matrix Math

Transforms and projections.

- Translation, Rotation, Scale — positioning objects
- Matrix Math — combining transforms
- Orthographic Projection — a camera-style view

## Shaders

- Inter Stage Variables — passing data from vertex to fragment shaders

## Textures

- Textures — sampling images on the GPU
- Importing Textures — loading images from the browser
